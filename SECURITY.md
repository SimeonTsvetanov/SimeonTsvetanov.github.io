# Security policy — simeontsvetanov.github.io (hub site)

## Reporting a vulnerability
Please report privately through GitHub:
https://github.com/SimeonTsvetanov/SimeonTsvetanov.github.io/security/advisories/new

Do not open a public issue for security problems. Include what is affected, steps to reproduce
and the impact you expect. For a vulnerability in a specific app, use that app's repository.
Machine-readable contact: https://simeontsvetanov.github.io/.well-known/security.txt

## What to expect
- Acknowledgement within 7 days.
- An assessment and a plan within 14 days.

## Scope
In scope: this repository — the static hub page, its build script and GitHub Actions workflows.
Out of scope: GitHub Pages itself, denial of service by volume, and automated scanner reports
without a demonstrated impact.
